# Drop an engine model here

Put a `.glb` (preferred) or `.gltf` file in this folder and reload the panel.
It replaces the built-in procedural engine automatically — no code changes.

The model is centred, scaled to fit, and sliced along its longest horizontal
axis into one clickable band per branch, with a gold ring marking each. So any
engine model works; it does not need named cylinders or any editing.

**Format:** buy or export as **glTF / GLB**. `.max`, `.fbx`, `.obj`, `.c4d` and
`.blend` will not load in a browser — convert them first (Blender: File →
Export → glTF 2.0).

**Size:** keep it under ~50 MB, or the panel will be slow to open. A 4K-textured
model is usually fine once exported as GLB with compressed textures.

Files in this folder other than this README are gitignored, so a purchased
model is never committed.
